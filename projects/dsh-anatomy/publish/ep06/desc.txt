拆开 DSH · 第六集（完结）。前五集都在拆，这一集反过来：往里装一个自己的东西。

一个包可以往三个地方伸手：
· 工具 → ctx.tools.register，模型下一步的菜单里就多一项
· 命令 → ctx.commands.register，一条斜杠命令，handler 直接返回给界面
· 面板 → 客户端半边，ctx.slots.inject + ctx.slots.register 挂到界面留好的空位上

两个容易忽略的差别：
· 工具跑完是 tool/call → tool/result，进日志也进模型可见的历史；
  命令跑完是成对的 command/run → command/done，log-only，永远不进模型的历史。
· 装包的结果看 application：applied 是已经活了；restart-required 会带五种原因之一
  （no-hmr / package-moved / host-module / unmanaged-plugin / module-comparison）。

现场演示（真装、真卸）：
造一个真包 demo/greet：一个工具、一条命令、一个 dock 面板。
plugin_manager install_bundle → application: "applied"，工具清单多出 greet，
输入框下面多出 { id: "greet", order: 50, active: true }；
remove_bundle 之后 dock 占位 7 → 6，profile 的 package.json / cordis.patch.yml / node_modules 无残留。
